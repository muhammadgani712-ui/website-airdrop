⚠️ Waspada Airdrop Scam! Tips Menghindari Penipuan Crypto

Keamanan

Seiring meningkatnya popularitas airdrop crypto, kasus penipuan berkedok airdrop juga semakin marak. Dalam 3 bulan terakhir saja, tercatat kerugian lebih dari $50 juta akibat airdrop scam di seluruh dunia.

🚨 Ciri-Ciri Airdrop Scam

Kenali tanda-tanda berikut agar kamu tidak menjadi korban:

  • Meminta Private Key / Seed Phrase — Airdrop asli TIDAK PERNAH meminta ini
  • Meminta kirim uang duluan — "Kirim 0.1 ETH untuk klaim airdrop"
  • Link mencurigakan — URL yang mirip tapi bukan website resmi (typosquatting)
  • DM di Discord/Telegram — Admin proyek asli tidak akan DM duluan
  • Too good to be true — "Klaim 10,000 token gratis senilai $50,000!"
  • Approve unlimited token — Meminta approval jumlah token tak terbatas

🛑 JANGAN PERNAH memberikan seed phrase atau private key kamu kepada siapapun, dalam kondisi apapun. Tidak ada airdrop yang membutuhkan seed phrase untuk klaim.

✅ Cara Melindungi Diri

  • Verifikasi link resmi — Selalu cek dari website dan Twitter resmi proyek
  • Gunakan wallet terpisah — Buat wallet khusus untuk airdrop, jangan pakai wallet utama
  • Cek kontrak di block explorer — Periksa smart contract sebelum approve
  • Jangan klik link di DM — Abaikan semua DM yang menawarkan airdrop
  • Gunakan Revoke.cash — Rutin cek dan revoke approval yang mencurigakan
  • Aktifkan hardware wallet — Gunakan Ledger/Trezor untuk aset bernilai besar

✅ Tips Aman: Gunakan wallet terpisah khusus untuk airdrop hunting. Jangan pernah simpan aset bernilai besar di wallet yang sering digunakan untuk interaksi airdrop.

Contoh Kasus Scam Terbaru

1. Fake LayerZero Airdrop (Oktober 2026) — Website palsu mirip LayerZero meminta pengguna connect wallet dan approve token unlimited. Lebih dari 500 wallet terkuras dengan total kerugian $2.3 juta.

2. Discord Hack (September 2026) — Server Discord sebuah proyek L2 diretas, bot mengirim link phishing ke semua member. Korban yang klik dan approve kehilangan aset mereka.

3. Airdrop Token Palsu (Agustus 2026) — Token tidak dikenal muncul di wallet pengguna. Saat mencoba swap, pengguna diarahkan ke situs phishing yang menguras wallet.

Kesimpulan

Airdrop adalah cara yang sah untuk mendapatkan token gratis, tapi kamu harus selalu waspada. Lakukan riset sendiri (DYOR), verifikasi semua informasi dari sumber resmi, dan jangan pernah terburu-buru mengambil keputusan. Keamanan aset kamu adalah prioritas utama.
